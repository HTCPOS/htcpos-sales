# HTCPOS - تطبيق AltStore

## الخطوات

### 1. أنشئ مستودع (Repository) جديد على GitHub
- روح https://github.com/new
- اسم المستودع: htcpos-app (أو أي اسم)
- خليه Public أو Private (الاتنين شغالين)
- ما تضفش README ولا .gitignore من عند GitHub، سيبها فاضية
- دوس Create repository

### 2. ارفع الملفات دي كلها
- فك ضغط htcpos-app.zip على جهازك
- في صفحة المستودع الفاضي، دوس "uploading an existing file"
- اسحب مجلد htcpos-app كله (بكل اللي جواه: www، .github، package.json، capacitor.config.json) وافلته في الصفحة
  - لو المتصفح ما قبلش السحب المباشر للمجلد، افتح المجلد وارفع كل الملفات والمجلدات الفرعية واحد واحد بنفس الترتيب
- اكتب أي وصف واضغط Commit changes

### 3. شغّل البناء
- روح لتبويب "Actions" فوق في المستودع
- لو طلب منك تفعيل Actions، وافق (Enable)
- هتلاقي "Build iOS App (AltStore)" في القائمة الجانبية - دوس عليه
- دوس "Run workflow" (زر أخضر) -> Run workflow تاني للتأكيد
- استنى 5-10 دقايق (البناء بيشتغل على جهاز Mac افتراضي مجاني من GitHub)

### 4. نزّل ملف .ipa
- لما يخلص (علامة صح خضرا)، دوس على البناء اللي خلص
- تحت "Artifacts" هتلاقي "HTCPOS-ipa" - نزّله (هيجيلك كملف zip فيه HTCPOS.ipa جواه)
- فك الضغط تلاقي HTCPOS.ipa

### 5. ثبّته على الآيفون عن طريق AltServer
- ثبّت AltServer على جهاز الكمبيوتر (ويندوز أو ماك) من https://altstore.io
- وصّل الآيفون بنفس الواي فاي بتاع الكمبيوتر (أو بالكابل)
- من قائمة AltServer الصغيرة (بجانب الساعة) اختار "Install .ipa" -> اختار HTCPOS.ipa
- سجل دخول بحساب Apple ID مجاني لما يطلب منك (بيتستخدم بس للتوقيع، آمن)
- التطبيق هيتثبت على الآيفون تلقائيًا

## ملاحظات مهمة
- التطبيق مجرد غلاف بيفتح موقعك الحي htspos-sales.netlify.app - أي تعديل ترفعه على الموقع يظهر فورًا في التطبيق من غير إعادة بناء
- تحتاج تعيد الخطوات 3-5 بس لو غيرت حاجة في إعدادات التطبيق نفسه (الأيقونة، الاسم، الصلاحيات)
- التطبيق (بحساب Apple ID مجاني) بينتهي كل 7 أيام - سيب AltServer شغال على الكمبيوتر دايمًا وفعّل "تحديث التطبيقات بالخلفية" في إعدادات الآيفون عشان يتجدد لوحده
